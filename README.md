# 基礎胰島素滴定示範計算器

Glargine U300 基礎胰島素滴定的**教學示範**單頁網頁，供醫學會演講現場示範與衛教使用。**非臨床決策工具，實際劑量請依醫師指示。**

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需安裝、不需後端。所有計算都在頁面內完成，不儲存、不傳送任何資料（未使用 localStorage 或任何網路請求；僅載入 Google Fonts 字型，離線時自動改用系統字型）。

## 功能

- 輸入：目前每日劑量、最近 3 天空腹血糖、有無低血糖（<70 mg/dL 或有症狀）、評估日
- 輸出：建議新劑量、一句白話理由、計算過程、下次調整日期
- 規則參數可在畫面上直接修改：
  1. **減量（優先）**：任一天空腹 < 70 或有低血糖症狀 → 減 10%／15%／20%（預設 10%，取整數、小數無條件捨去）
  2. **加量**：3 天平均 > 目標上限（預設 130）→ +2 U
  3. **維持**：3 天平均在目標 80–130 內 → 維持；平均低於下限但無低血糖 → 也維持並提醒觀察
  - 每 3 天評估一次
- 示範情境 A／B／C 一鍵帶入（偏高、已達標、有低血糖）
- 14 天模擬圖（劑量與空腹血糖分上下兩圖、共用天數軸），可滑鼠／觸控／方向鍵逐日查看，並附數據表
- 「放大字級」按鈕方便投影；支援淺色／深色模式與手機版面
- 頁面底部固定顯示：「教學示範用，實際劑量請依醫師指示」

## 14 天模擬的病人模型（虛構）

- 空腹血糖 ≈ 基準值 − 敏感度 × 有效劑量 + 隨機變動
- 有效劑量以指數方式逐日趨近實際劑量（時間常數約 1.3 天，約 3–4 天達穩定，對應 U300 的藥動特性）
- 基準值由輸入的 3 天平均與目前劑量反推；敏感度（預設每 1 U 降 4 mg/dL）與每日變動（預設 ±10 mg/dL）可在畫面調整
- 模擬中若出現低血糖，當天即依規則減量並重新起算評估間隔

此模型只用來示範「小步、定期調整」的節奏，不代表任何真實病人的反應。
